# Python 学习仓库（个人工作区）

本目录是 `hub-usME` 仓库的本地工作区，用于每周 Python 学习代码与作业的版本管理。

- 远程仓库：https://github.com/LlxCorey/hub-usME.git
- 个人目录：`庄群新/`（按周建立 `weekXX` 子文件夹）

## 目录结构

```
庄群新/
├── week01/
│   ├── README.md
│   ├── 第一周记录.md
│   └── 环境自检.py
└── week02/ ...
```

## 提交规范

- 只修改自己名字目录下的文件，不动其他同学和老师的文件
- 文件名中不包含空格和 `.` 等特殊符号
- 每周五前提交当周作业，等待老师审批通过

## 常用命令

```bash
git pull                     # 拉取老师与同学的最新提交
git add 庄群新/               # 暂存本周作业
git commit -m "week01: 提交第一周作业"
git push                     # 推送到远程仓库
```
