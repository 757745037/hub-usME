## 四、基础语法要点

- **变量与类型**：`int`、`float`、`str`、`bool`、`list`、`tuple`、`dict`、`set`
- **运算符**：算术 `+ - * / // % **`、比较 `== != > <`、逻辑 `and or not`
- **输入输出**：`input()` 返回字符串，`print()` 支持多参数与 `f-string` 格式化
- **类型转换**：`int()`、`float()`、`str()`、`list()`

示例：

```python
name = input("请输入姓名：")
age = int(input("请输入年龄："))
print(f"你好，{name}！明年你 {age + 1} 岁。")
```
